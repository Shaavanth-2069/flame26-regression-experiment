
# FLAME'26-Style Regression Experiment: Student Marks Prediction

## Project Overview
This is an independent educational demonstration of supervised
machine learning using Linear Regression.

The application estimates illustrative exam marks from study hours
and displays a regression graph and evaluation metrics.

## Objectives
- Understand supervised learning and regression.
- Train a Linear Regression model.
- Make predictions using a user-selected input.
- Visualize observations and the regression line.
- Evaluate predictions using MAE and R².

## Technologies
- Python
- Streamlit
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
The application uses 20 illustrative sample records.
The values are demonstration data, not real student records.

## Run Locally
1. Install Python 3.10 or later.
2. Install the dependencies:
   pip install -r requirements.txt
3. Start the application:
   streamlit run app.py
4. Open the local URL shown in the terminal.

## Machine Learning Workflow
1. Load the illustrative dataset.
2. Split the data into training and testing sets.
3. Train a Linear Regression model.
4. Generate predictions.
5. Evaluate using Mean Absolute Error and R².
6. Display the regression graph and results.

## Limitations
This small illustrative dataset is not suitable for reliable
real-world academic predictions. The results are for learning
purposes only.
